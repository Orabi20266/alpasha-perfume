# AL PASHA Perfume — نسخة React

متجر **AL PASHA / الباشا للعطور** — عطور شرقية وفرنسية فاخرة، معاد بناؤه بـ React + Vite + Tailwind CSS مع واجهة عربية RTL وحركات UI حديثة.
يبيع المتجر العطور الرجالية والنسائية، العود ودهن العود، البخور والمباخر، زيوت المسك، وأطقم الهدايا، ويعمل بدون خادم (البيانات محفوظة في `localStorage`).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
npm run lint
```

## الصفحات

| المسار | الوصف |
| --- | --- |
| `/` | الصفحة الرئيسية: البانر، الأقسام، الفلاتر، العروض، آراء العملاء |
| `/offers` | عروض الموسم: شرائح الخصم التنازلي والمنتجات المشمولة |
| `/raffle` | سحب الباشا الذهبي: تسجيل رقم السحب ونتيجة السحب |
| `/admin` | لوحة التحكم — محمية بكلمة مرور |

> المشروع يستخدم `BrowserRouter` مع ملف `public/_redirects`، لذا تعمل الروابط المباشرة مثل `/admin` على Cloudflare Pages وأي استضافة تدعم SPA fallback.

## لوحة التحكم

- الرابط: `/admin`
- كلمة المرور الافتراضية: `pasha2026` (يمكن تغييرها من تبويب «الإعدادات»)

التبويبات:

1. **نظرة عامة** — إحصاءات، أحدث الطلبات، مخزون منخفض.
2. **المنتجات** — إضافة، تعديل، حذف، بحث، إدارة الأسعار والمخزون والمواصفات والشارات.
3. **العروضات** — نصوص صفحة العروضات، شرائح الخصم التنازلي، بانر الرئيسية، والمنتجات المشمولة.
4. **سحب الباشا** — إعدادات السحب، أرقام السحب المرتبطة بالطلبات، واختيار الفائز عشوائياً.
5. **السوشيال ميديا** — واتساب، هاتف، بريد، عنوان، ساعات العمل، وروابط فيسبوك/إنستغرام/إكس/لينكدإن/تيك توك.
6. **الطلبات** — متابعة طلبات الشراء وطلبات عروض السعر، رقم السحب، تغيير الحالة، حذف، مراسلة العميل.
7. **الإعدادات** — اسم المتجر، العملة، الضريبة، الشحن، كلمة المرور، تصدير JSON، استعادة البيانات الافتراضية.

## الميزات

- الصفحة الرئيسية تبدأ مباشرة بشبكة المنتجات مع فلاتر سريعة، بدون بانر يدفع المنتجات للأسفل.
- سلة جانبية مع حساب خصم الموسم والضريبة والشحن وحد الشحن المجاني.
- عروض الموسم: شرائح خصم تلقائية تبدأ من 10% عند 350 ₪ وتتناقص مع زيادة قيمة الطلب (بدون كود خصم).
- سحب الباشا الذهبي: رقم سحب فريد لكل طلب شراء وتسجيله من صفحة `/raffle`.
- إتمام الطلب إلكترونياً أو عبر واتساب (زرّان في نهاية نموذج الطلب).
- المدينة حقل نصي حر (بدون قائمة منسدلة).
- الدفع عند الاستلام فقط.
- العملة الافتراضية: الشيكل `₪` وقابلة للتغيير من اللوحة.
- المفضلة، البحث الفوري، فلترة الأقسام، شريط السعر الأقصى، الترتيب.
- نافذة معاينة سريعة لكل منتج + طلب عرض سعر خاص.
- روابط واتساب: `+970 599 123 456` وصفحات التواصل الرسمية.
- حركات ظهور عند التمرير، انتقالات، واحترام `prefers-reduced-motion`.

## ملاحظات

- كل التعديلات تُحفظ في متصفح المستخدم فقط. لمزامنة السحب والطلبات بين عدة أجهزة اربط المشروع لاحقاً بقاعدة بيانات (Supabase/Firebase) أو أي API؛ حالياً أرقام السحب والطلبات موجودة في متصفح كل زائر.
- الصور: كل منتج له رسم SVG أصلي داخل `src/data/art.js`، ويمكن للأدمن إدخال رابط صورة خارجية ليحل محل الرسم.
- لإعادة تعيين كل شيء: لوحة التحكم ← الإعدادات ← «استعادة البيانات الافتراضية».
